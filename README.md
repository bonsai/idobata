# idobata

**気軽に集まり、話し、ゆるくつながる場所。**

idobata（井戸端）は、特定の相談や投稿を目的にするのではなく、人が集まって日常の話を交わすためのコミュニケーションの場です。

## 解決したいこと

オンラインの会話は、明確な用事や共通の趣味、継続的な関係がないと始めにくいことがあります。一方で、何気ない雑談から、気づきや共感、新しいつながりが生まれることもあります。

idobata は、話題を決めすぎず、参加者が気軽に会話できる場を探ります。

## このプロジェクトの役割

| プロジェクト | 中心となる体験 |
| --- | --- |
| **idobata** | 人が集まり、雑談を続けられる |
| [kitsuenjo](https://github.com/bonsai/kitsuenjo) | たまたま居合わせた人との短い会話が始まる |
| [RUSUDEN](https://github.com/bonsai/RUSUDEN) | 届いた悩みや相談の声を聞き、声で返事をする |
| [line-koe-compe](https://github.com/bonsai/line-koe-compe) | 声をテーマにした企画・コンペに参加する |
| [the-king-with-donkey-ears](https://github.com/bonsai/the-king-with-donkey-ears) | 誰にも言えない気持ちを吐き出す |
| [message-in-a-bottle](https://github.com/bonsai/message-in-a-bottle) | 誰かに届くかもしれないメッセージを送る |
| [balloon-seed](https://github.com/bonsai/balloon-seed) | 夢やアイデアの種を世界に放つ |

**idobata と kitsuenjo の違い:** idobata は「集まって雑談する場」、kitsuenjo は「偶然居合わせたことから会話が始まる場」です。

## 大切にすること

- **気軽さ:** 立派な意見や目的がなくても参加できる
- **雑談の余白:** 話題を固定せず、会話の流れを大切にする
- **参加の自由:** 聞くだけでも、話しても、途中で抜けてもよい
- **安全と尊重:** 個人情報、嫌がらせ、脅迫、差別などへの対策を考える
- **プライバシー:** 公開範囲や記録の扱いを明確にする

## 想定する体験

1. 人が会話の場に入る
2. その場の話題や参加者のひと言から雑談が始まる
3. 話したい人が話し、聞きたい人は聞く
4. 会話が自然に移り変わり、参加者は自由に退出できる

これは体験を検討するための仮説であり、実装済みの機能を示すものではありません。

## いま検証したいこと

- 初対面でも会話を始めやすくするには何が必要か
- 文字・音声・リアルタイムのどれが場に合うか
- 会話が途切れても気まずくならない設計は可能か
- 荒らしや迷惑行為を防ぎながら、気軽さを保てるか
- 会話を記録・保存しない選択肢が必要か

## プロジェクト方針

- まずは会話体験の仮説を小さく検証する
- 他プロジェクトと目的や実装を混同しない
- 共通化が必要な場合も、まずは仕様や成果物へのリンクで連携する
- 具体的な機能・技術・運用方針は、検証結果をもとに決める
